# 🕌 Masjid Al-Rahma — Official Website

Welcome to the digital home of **Masjid Al-Rahma** (Al-Rahma Islamic Center of Phoenix)!

This site is your one-stop hub for prayer times, community events, Islamic education, and everything happening at our beloved masjid. Whether you're a longtime member or a curious neighbor — you belong here. 🤲

## ✨ Features

- 📅 **Live Prayer Times** — Always know when to pray
- 📰 **Community News & Events** — Stay in the loop
- 📚 **Islamic Education** — Resources for all ages
- 🤲 **Donate** — Support the masjid from anywhere
- 🗺️ **Umrah Trip Sign-ups** — Join us on the journey of a lifetime
- ❓ **FAQ** — Answers to everything you wanted to know

## 🛠️ Built With

- [Next.js 15](https://nextjs.org/) — React framework for production
- TypeScript — Because bugs are *haram* 😄
- Deployed on [Netlify](https://www.netlify.com/)
